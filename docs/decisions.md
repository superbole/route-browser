# Decisions

Why it is like this, and what was rejected. A row per decision, written when it is made.

| Decision | Rejected, and what it would have cost |
|---|---|
| **Downloads and the page live in `~/.route-browser`, not in this folder** (2026-11-19). | In the code folder: a fresh download, `git clean` or a deleted worktree takes years of downloads with it, and the page (which shows where you live) sits one `git add` from a public repo. |
| **Its own public repo** (2026-11-19). | Sending zips: every fix means a new zip, and nobody knows which version they have. Private: each person needs a GitHub account and an invite. The repo holds code only, so public shows nothing personal. |
| **The page computes no-stop stretches; `loops.py` only records where rides slowed, per speed level** (2026-11-19). | Stretches in Python: the strictness sliders would need a rebuild for every change. |
| **Default stop rule: slowing under 70% of usual speed on 1 ride in 4** (2026-11-19). | Half speed on 40% of rides: a tested loop showed one 66-min "stretch" through robots, stop streets and pinch points that a rider cannot hold an effort through. |
| **A repeat needs 90 s+ efforts, and a session 3+ of them (or 2 of 5 min+)** (2026-11-19). | Any two efforts on one road: every out-and-back over a hill looked like 2 reps. |
| **Ride data gzipped and base64 inside the page, unpacked by the browser's DecompressionStream** (2026-11-19). | Plain JSON: 85 MB for a full history. A separate data file: a page opened by double-click cannot fetch a local file. |
| **A nightly scheduled task, not a "fetch new" button** (2026-11-19). | A button: a plain file cannot run Python, so it needs a local server running whenever the page is open. |
| **A failed fetch writes `fetch_status.json` and the page shows a red banner** (2026-11-19). | A log file only: an expired key would stop updates silently, and nobody reads the log. |
| **The nightly task runs on battery, and `refresh.ps1` reads the key from the registry if the task's environment lacks it** (2026-11-19). | Windows defaults: the task sat "Queued" on a laptop on battery, and a key saved after logon was invisible to it until a re-login. Both looked like "key not set" on the page. |
| **The side panel is tabs, and leaving a tab puts the map back to all rides** (2026-11-21). | Stacked sections with show/hide ticks: a sixth section made a long scroll, and two map-click tools (A to B, the builder) would fight over the same click. Keeping a tab's selection when leaving it: the map stays narrowed with nothing on screen saying why. |
| **The route builder routes over a graph of all shown rides (~50 m cells, edges at mean moving time), not over whole rides** (2026-11-21). | Only rides that passed both points (the A-to-B matcher per leg): tried first, and in the densest part of the map most legs found no way, because no single ride covered them. |
| **A graph node is a cell plus a direction of travel (within 30°), so a route turns only where some ride turned** (2026-11-21). | One node per cell: every crossing was a junction, so routes dropped off bridges onto the road below and U-turned across a central barrier onto the other carriageway (reported on real rides). Finer cells: carriageways are 20 to 40 m apart and bridges sit right over the road, so any size small enough to split them breaks up one road ridden on different days. Cost of the choice: a crossroads you only ever rode straight through cannot be turned at. On 300 random 3 to 12 km legs every one still found a way, about 11% slower on average than with the false shortcuts. |
| **Map tiles from Esri World Street Map, not tile.openstreetmap.org** (2026-11-21). | A double-clicked page (how the README says to open it) sends no Referer. OSM's own tiles: blocked with "Access blocked" on a real double-click, though not every time in a test. CARTO: "API key required" without a Referer. Keeping OSM and requiring `serve.py`: one more thing running before the page works. Esri loaded keyless from a `file://` page in Edge. |
| **Alternatives by making used roads 1.5x dearer and re-routing, kept if 30%+ different and under 1.5x the fastest time** (2026-11-21). | True k-shortest paths: the next few are the same road with a 50 m wiggle. No time cap: the third "way" was a long detour. |
| **Roads count one way unless "Use roads both ways" is ticked** (2026-11-21). | Both ways by default: one-way streets and climbs ridden only downhill would be routed the wrong way, at the downhill time. |
| **Per-ride numbers for a spot come from A to B, opened on the spot's ends** (2026-11-24). | A ride list inside New spots: a second table of times, W and bpm to build and keep in step with A to B, which already does it. |
| **The test window takes a speed the rider types, not a power** (2026-11-24). | Watts to speed: needs a drag and weight model per rider, and wind swings it more than the model would gain. A to B shows the speed actually held there. |
| **On New spots the length limits apply to climbs too; on Routes they do not** (2026-11-24). | Climbs unfiltered on New spots: a "30 min+" list still showed 4-min climbs (reported). Filtering climbs on Routes as well: the default 8 min would hide most of them there. |
